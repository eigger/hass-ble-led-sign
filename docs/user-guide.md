# BLE LED Sign User Guide

[English README](../README.md) · [한국어 README](../README.ko.md) · [Troubleshooting](troubleshooting.md)

This integration provides unified Home Assistant control for Bluetooth Low Energy (BLE) matrix LED signs.

## Architecture and Supported Hardware

The integration uses a modular driver architecture where each hardware family lives under `custom_components/ble_led_sign/drivers/` and exposes a consistent set of entities and actions.

### Driver Families

| Driver | Device Series | Advertising Match | Capabilities |
|--------|---------------|-------------------|--------------|
| `coolled` | CoolLED 1248, CoolLED S/X, CoolLED M/U/UX, CoolLED 536, iLed* | Name prefix or UUID `0xFFF0` | Power, brightness, scroll speed, scroll mode, text, images, animation, JT programs, music equalizer, icons |
| `ipixel_color` | `LED_BLE_*` (iPixel Color) | Name prefix `LED_BLE*` or UUID `0x00FA`, `0xAE00` | Power, brightness, text speed, display flip, clear, countdown, PNG/GIF transfer, control frames |

### Color Types

LED signs report or default to specific color types:

| Type | Label | Supported Colors |
|------|-------|------------------|
| 0 | Single | Monochrome: `off`, `on`, `black`, `white` |
| 1 | Seven | 7 colors: Single + `red`, `yellow`, `green`, `cyan`, `blue`, `purple` |
| 2+ | Colorful | Full RGB: Seven + `orange`, `pink`, `#RRGGBB` (quantized to nearest panel palette) |

The detected panel size, firmware revision, and color type appear in the Home Assistant Device Registry after discovery.

## Entities

Entities are registered based on what the detected device driver supports:

| Platform | Entity | Description |
|----------|--------|-------------|
| `light` | Display Power | Turn display on/off and control brightness. For CoolLED, scroll modes are exposed as light effects. |
| `number` | Scroll Speed | Matrix scrolling speed (0–255). |
| `number` | Countdown Minutes | Countdown timer duration in minutes (iPixel Color). |
| `select` | Scroll Mode | CoolLED animation modes (`static`, `left`, `right`, `up`, `down`, `snowflake`, `picture`, `laser`). |
| `select` | Display Mode | iPixel Color modes (`normal`, `clock`, `stopwatch`, `scoreboard`). |
| `switch` | Flip Display | Rotate display 180° upside down (iPixel Color). |
| `button` | Clear Display | Clear current content or device slots (iPixel Color). |
| `button` | Start Countdown | Start countdown timer on the display (iPixel Color). |
| `text` | Scroll Text | Live text input sent immediately to the display. |
| `image` | Last Sent Display | The last rendered image successfully transmitted to the sign. |
| `image` | Render Preview | Preview generated by `dry_run: true` or previous renders without BLE transmission. |

## Configuration Options

Configure via **Settings → Devices & Services → BLE LED Sign → Configure**:

| Option | Default | Range | Description |
|--------|---------|-------|-------------|
| **Device Password** | `000000` | 6 chars | Authentication password for protected CoolLED and iPixel models. |
| **Retry Count** | 3 | 1–10 | Connection retry count upon BLE communication failure. |
| **Packet Delay (ms)** | 15 | 0–1000 | Delay in milliseconds between consecutive BLE packet transmissions. Increase to 50–100 ms if packet loss occurs. |

## Declarative Rendering with `imagespec`

The `ble_led_sign.write` action renders layouts using [imagespec](https://github.com/eigger/imagespec) — an expressive declarative YAML syntax.

### Key Characteristics

- **Canvas Size**: Dimensions (`width` and `height`) match the sign's hardware resolution (e.g. 48 × 12).
- **Palette Quantization**: Colors outside the panel palette are mapped to the nearest supported color.
- **Canvas Rotation**: `rotate: 0`, `90`, `180`, or `270` operates in canvas mode with fixed hardware dimensions.
- **Fonts**: Bundled with pixel-optimized `Galmuri14.ttf`. Custom TrueType fonts can be placed in `www/fonts/`.
- **History Plots**: The `plot` element queries historical sensor values directly from Home Assistant **Recorder**.
- **Icons**: Standard Home Assistant `weather-*` and Material Design icons are supported.

## Service Reference

### `ble_led_sign.write`

Render declarative layout elements and send the bitmap to the sign.

```yaml
action: ble_led_sign.write
target:
  device_id: <your_device_id>
data:
  payload:
    - type: rectangle
      x_start: 0
      y_start: 0
      x_end: 47
      y_end: 11
      fill: black
    - type: text
      value: "21.5°C"
      x: 2
      y: 1
      size: 10
      color: cyan
    - type: icon
      x: 36
      y: 1
      value: "weather-partlycloudy"
      size: 10
      color: yellow
  rotate: 0
  background: black
  dry_run: false
```

### `ble_led_sign.send_text`

Send simple scrolling or static text.

```yaml
action: ble_led_sign.send_text
target:
  device_id: <your_device_id>
data:
  text: "Home Assistant Notification"
  color: "00FF00"
```

### `ble_led_sign.send_image`

Send a local image file (PNG/JPEG) directly.

```yaml
action: ble_led_sign.send_image
target:
  device_id: <your_device_id>
data:
  image_path: "/config/www/images/logo.png"
  threshold: 128
```

### `ble_led_sign.send_animation`

Send an animated GIF to the display.

```yaml
action: ble_led_sign.send_animation
target:
  device_id: <your_device_id>
data:
  image_path: "/config/www/animations/cat.gif"
  speed_ms: 100
```

### `ble_led_sign.send_command`

Send driver-specific control commands (e.g. iPixel clock, scoreboard, DIY mode).

```yaml
action: ble_led_sign.send_command
target:
  device_id: <your_device_id>
data:
  command: "clock"
  value: [1, true, true]
```
